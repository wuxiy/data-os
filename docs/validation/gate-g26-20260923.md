## 方案边界（先声明，验收以此为准）

**不做任意自然语言转 SQL，不引入 LLM 生成查询**。受控问数 = 已验证问题（migration 种子）→ 确定性匹配（code/question/aliases，归一化：去首尾空白/去全角问号/折叠空白/小写）→ 控制面参数校验 → data-api 已发布数据服务执行（复用 SQL 模板/机构范围/熔断/审计，服务身份为独立 Keycloak client `dataos-assistant-bff`）。分类器 seam 保留在 `AssistantAdminService.match()`（决策智能线 R3 的 AssistantAdapter 接缝不预锁定引擎）。门户明示「Beta，仅已验证问题，不做任意自然语言转 SQL」。

## 工程备注（dev 实抓，均已修复入 `12dc0c4`）

- **JDK HttpClient h2c 丢请求体（G9 老坑重现）**：dev 首连 data-api internal 路由 422「body missing」——`RestClient.builder().build()` 默认 HTTP/2 对明文端点发 h2c Upgrade，uvicorn 拒绝升级并**丢弃请求体**；本地 HttpServer 桩测不出（sun HttpServer 容忍 h2c）。修复：`AssistantDataApiClient` 改经 `AdapterHttp.restClient()`（强制 HTTP/1.1，3s/60s 超时）——与 G9 的 Java→FastAPI 强制 HTTP/1.1 结论同源。新增 `AssistantDataApiClientTest` 传输契约测试（POST 路径模板/JSON 体/Bearer/404→SERVICE_OFFLINE）锁定线格式。
- **@Value 宽松绑定不认 DATAOS_ASSISTANT_ 连写形态（H3 老坑重现）**：env 在容器内而 @Value 读空→执行面「未配置」。修复：application.yml 显式声明五键 `${DATAOS_ASSISTANT_*:}` 映射。两坑均为此前记忆库在档教训，重现在新代码路径——传输层 client 构造应默认走 AdapterHttp 的结论值得在下次 agents 文档巡检时固化。
- **跨租户口径**：dev 全局认证 DISABLED，TenantScope 忽略请求租户头（dev 无 403 现场）；ENFORCED 语义由 AssistantSecurityTest（JWT 桩 MockMvc）锁定：租户外问题不可见、越租户参数 403、跨租户反馈 404。
- SERVICE_OFFLINE 拒答文案为「不存在或未发布」（data-api 404 无法区分未知 code 与未发布）——语义诚实但粒度粗，记 backlog 不阻塞。
- 演练期 data-api 重启后需 ~15s 才恢复应答（healthcheck start-period 内 503 属预期）。
