## 发现与坑（新增）

1. **FAB `protect()` 的 Public 短路**：Flask-AppBuilder 4.5 对 Public 角色持有的权限走 `is_item_public` 直接放行且**跳过 JWT 校验**——给 Public 授 REST 读权限等于把「带 token 的服务调用」降级成匿名。守卫已写入 dev Superset 配置注释：嵌入链授权只挂 `embedded_guest` 这类专用角色，永不挂 Public。
2. **CI 安装清单打地鼠**：quality-runner CI 安装列表与 pyproject 双轨漂移（httpx→jwt→…）；已按测试面 import 闭包补全，但双轨本身仍在——候选改进：CI 改从 pyproject 派生安装（记 backlog）。
3. **被遮蔽的存量问题会连环暴露**：CI 恢复过程中同一 job 依次暴露测试失败→镜像 CVE（control-plane）→镜像 CVE（quality-runner），共三轮推送；每一轮都在本地先行复刻验证（UTC 全量、docker build + trivy 同参数）再推。
4. **dbt-core 1.10→1.12 升级**：本地测试全绿，但 dev 环境 quality-runner 重部署后的真实 dbt 运行（quality/dbt 项目）尚未验证——记 backlog 待 dev 部署时核验。
5. **mpi-service 依赖未扫**：CI 无 mpi job，其 Spring Boot 3.4.x 栈存在同款 CVE 面——记 backlog（H5 CI 矩阵候选）。
