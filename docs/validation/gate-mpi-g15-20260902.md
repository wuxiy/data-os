# Gate 15 验收报告：MPI T5 混合策略（V1 合取守卫 + V2 分数否决）

> 日期：2026-09-02
> 方案载体：G14 gate 报告 §四核心发现与 §七延后项（`docs/validation/gate-mpi-g14-20260828.md`）——本报告即其落地与验收
> 阶段定位：核心职责 3「完善算法效果」；关闭备忘 T5a（影子实验部分）

## 一、交付物

| 层 | 内容 |
| --- | --- |
| 混合引擎 | `MpiHybridMatcher`（implements PairScorer，version "v1+v2"）：AUTO 判定权完全归 V1 合取守卫；否决带——V1 判 REVIEW/NO_MATCH 且 V2 分数 < tVeto → 直接 NO_MATCH |
| 阈值 | `MpiWeights.tVeto` = 0.42（标定集 min 同人分 0.43 − 0.01，零误否约束——与 T_AUTO=max 非同人 + 0.01 镜像的确定性纪律） |
| 评测 harness | 三引擎同评（v1 / v2 / hybrid，Engine 多态一行一引擎）+ tVeto 敏感度扫描 + 安全不变量断言（零误并、零误否、锚点） |
| 单元测试 | `MpiHybridMatcherTests` 4 例：否决触发 / 复核安全网不动 / 守卫高于分数（低分 AUTO 不降级）/ 版本标识 |
| 影子接入 | `MpiDecisionService` 证据追加 `hybrid` 行（分数 + 混合三态，否决触发带 `/V2-VETO` 后缀）；**决策权不变，仍 V1**；门户复核页经既有证据表自动渲染（标签「T5 混合（影子）」） |

## 二、设计依据（为何这个混合形态）

G14 核心结论：EP 字段集上身份信号在字段**合取**不在边际。据此两条设计裁决：

1. **分数不守门 AUTO**。dev 实测 6 个 V1 M-ep2 AUTO 的真实同人对（同卡但联系方式不一致的 EP 真实形态）只落在 V2 低分带 7.2-8.8 bit（T_AUTO=16.54）——若用分数确认 AUTO，V1 的自动化率 0.44 会被打回 V2 的 0.02。混合引擎里守卫先于分数：`rule.outcome() == AUTO_MATCH` 直接放行。
2. **分数只做否决（复核免除）**。V2 的可兑现价值（G14 §四）全部在 NO_MATCH 侧：非同人复核负担 -78%、锚点正确 NO_MATCH、可解释排序。否决带把这些价值接到 V1 的安全骨架上。

## 三、评测指标（冻结评测集 2142 对，正 717 / 负 1425；报告 `eval/reports/eval-report.json`）

| 引擎 | AUTO TP | 错误 AUTO | 同人丢失 | 非同人进复核 | F1 |
| --- | --- | --- | --- | --- | --- |
| V1 规则 | 314 | **0** | 0 | 1027 | 0.61 |
| V2 评分 | 12 | **0** | 5 | 226 | 0.03 |
| **T5 混合** | **314** | **0** | **0** | **212** | **0.61** |

**T5 混合在三安全轴上全部等于或优于两代**：自动化率保 V1 全量（314，守卫不动）、零误并（继承守卫）、零误否（V2 丢的 5 个同人对全部救回——它们只被免除复核的对是非同人）。非同人复核负担 1027→212（**-79.4%**），略优于纯 V2 的 226（V1 兜底 NO_MATCH 与否决带叠加）。

锚点对照（4 条人工裁决）：2 条 DIFFERENT_PERSON → 混合 NO_MATCH（V1 留在复核——锚点价值兑现）；2 条 SAME_PERSON → 混合 REVIEW（安全网不动，零丢失）。

## 四、tVeto 敏感度（评测集）

| tVeto | 同人被误否 | 非同人复核减免 | 非同人仍进复核 |
| --- | --- | --- | --- |
| 0.62（=T_REVIEW） | 5 | 815 | 212 |
| **0.42（定版）** | **0** | **815** | **212** |
| 0.0 | 0 | 796 | 231 |
| -6.0 | 0 | 785 | 242 |
| -12.0 | 0 | 264 | 763 |

曲线在 [0.42, -6] 平坦（减免 815→785，误否恒 0）：定版点取到平坦段上沿的零误否位置，对阈值漂移不敏感。0.62 处的 5 个误否即 V2 自身丢失的 5 对——T_REVIEW 不能直接兼作否决线，tVeto 独立标定是必要的。

## 五、决策权状态与切换裁决

决策权保持 V1。混合三态作为证据落库（hybrid 行），供复核工作台对照与后续裁决。**切换到混合引擎（预期收益：复核负担 -79%、锚点 NO_MATCH 正确处置）是域决策**，裁决输入：本报告指标 + dev 真实数据的 hybrid 影子分歧（rebuild 后可在复核页逐对查看）。裁决维度（G14 §五同款）：P-ep1 否决是否与人工直觉一致、有无混合 NO_MATCH 但人工判同人的对。
