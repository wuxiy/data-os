## 工程备注

- **dev 实抓一处设计口径并修正**：初版把「有合同事件」当作 DATA_SERVICE 阻断条件，dev 全部既有服务（seed 旁路创建）都没有合同事件——按清单原文「合同证据**可读取**」修正为合同证据=定义行（版本/状态）可读，事件清单作为证据内容如实呈现（可为空）；演练服务经真实发布流制造 PUBLISHED 事件。修正含单测翻转（`emptyContractHistoryIsHonestEvidenceButNotABlocker`）。
- 快照记录生成时刻的项目状态（主链快照在 IN_PROGRESS 生成，manifest 中 status 如实为 IN_PROGRESS）——证据是时点快照，验收钉住快照 id 保证可复核。
- `GET /api/v1/data-services` 不带 tenantId 返回 0 是既有行为（controller 不经 TenantScope 解析默认租户，`?tenantId=default` 正常）——与 G25 无关，门户传参不受影响，记备忘不扩项。
- dev 遗留演练数据：DL-G25-NEG/NEG2 两个 IN_PROGRESS 负例项目 + g25-demo-monthly-report（DEPRECATED 终态）+ DL-EP-202609（ACCEPTED）——无删除端点（计划固定 10 接口不含 DELETE 项目），留痕即审计。
