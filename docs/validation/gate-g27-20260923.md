## 方案边界

治理面只管**问题生命周期**（草稿→发布→停用→重新起草），不改变 G26 的受控执行边界：问答仍只匹配 PUBLISHED 问题、执行仍独占 data-api 已发布服务、审计仍逐次落库。**发布门**是本 gate 的核心语义：问题配置必须经真实试运行验证（最近一次成功试运行晚于最后一次编辑）才可发布——「已验证问题」名副其实，未验证的配置不能上线。

## 交付面

| V21 | `assistant_question_event`（CREATED/UPDATED/PUBLISHED/DEPRECATED/DELETED，动作 CHECK 约束；删除问题后事件按 code 保留可追溯——对齐 delivery_event 口径） |

| 生命周期 | 建=DRAFT（code 格式/租户唯一；question≤256、别名去重≤列表、schema 形状校验：name 唯一小写下划线/type∈四类/required 布尔/values 非空）；编辑/删除仅 DRAFT（code 不可改）；发布门=findLatestPassedTestRun(ANSWERED 且 detail like 'test-run%') > updated_at，否则 409 明示原因；停用 PUBLISHED→DEPRECATED（从问答面消失）；重新起草 DEPRECATED→DRAFT（重走完整门）；全部 CAS 条件推进（并发双推 0 行保护） |

## dev 真实链路证据（2026-09-23，镜像 0.2.0-g27-20260923 + 门户 dist 热更）

- **部署**：control-plane 单镜像切换（V21 迁移 `Migrating schema "public" to version "21 - assistant question lifecycle"` 一次成功，22 migrations validated）；data-api/quality-runner 未动（本 gate 无跨服务变更——粒度修正在控制面侧）。
- **治理演练 27 项全过**（`/tmp/g27-drill.py` 容器内跑，控制面经真实链）：
  1. 治理清单 3 种子 PUBLISHED；
  2. 建草稿 DRAFT + 重复 code 409；
  3. 发布门拦截（未试运行 409「尚无成功试运行」）；
  4. 试运行坏日期 → REFUSED_PARAM_INVALID + testRun 信封，且拒答后仍不可发布；
  5. 试运行成功（真实 Doris 执行，证据含 serviceCode）→ 发布 → 问数面出现 → **别名提问真实执行命中**；
  6. 发布态不可编辑 409；
  7. 停用 → 问数面消失（别名拒答 NO_MATCH）→ 停用态不可试运行（提示重新起草）；
  8. 重新起草 → 再发布被门拦（需重新试运行）→ 再试运行 → 再发布成功；
  9. 事件链完整（倒序 PUBLISHED/UPDATED/DEPRECATED/PUBLISHED/CREATED）；
  10. 发布态不可删 409、草稿删除成功；
  11. 种子问答不受演练影响。
- **粒度修正双向实证**：引用真实 DEPRECATED 服务（g25-demo-monthly-report，G25 演练下线留存）→ reason=`服务不可用: 服务已下线（DEPRECATED）: g25-demo-monthly-report`；引用不存在服务 → `服务不可用: 服务不存在或未发布: g27-no-such-service`。探测草稿均即时清理。
- **门户视觉验收**：真实浏览器（IAB）打开 `/assistant/workspace` 滚动至治理区块——快照证明 region「问数问题治理」含工具栏/说明/三行表格（种子 3 问、已发布徽章、未验证如实显示——种子为迁移直插无试运行记录）；截图经视觉评审通过（布局/徽章/按钮/列对齐无缺陷）。种子问题「未验证」显示是**如实口径**：发布门只约束管理面新发布，迁移种子未走过试运行，不伪造已验证。

## 工程备注

- **dev 实抓一处部署坑**：control-plane Dockerfile 直接拷 `target/*.jar`（无容器内构建），只跑 `mvn test` 不产包——首次部署的镜像仍含旧 jar，Flyway 报「No migration necessary」且无错误（静默旧版）。以 `unzip -l` 核对 jar 内迁移清单后 `mvn package -DskipTests` 重建解决。**守卫：部署前核对镜像内 jar 的迁移清单**（与 G20「部署 dev portal-dist 前查 bundle」同型）。
- 治理区块在 workspace `min-height: calc(100vh - 75px)` 折叠线下方——真实用户滚动即达（页面正常文档流），headless 视口截图拍不到属取证限制，非缺陷；视觉证据经真实浏览器滚动获取。
- 发布门比较口径：`updated_at` 在编辑/状态推进时前移，试运行**不**移动它（试运行不改问题行）——「最近成功试运行 > 最后编辑」语义稳定；发布本身前移 updated_at 不影响门（门只在 DRAFT 态检查）。
- 种子 3 问保持迁移事实源地位：管理面可停用/重开它们，但不提供改 code 的路径（code 不可改约束天然保护引用完整性）。
- dev 认证 DISABLED：治理角色矩阵由 AssistantSecurityTest（ENFORCED JWT 桩）锁定（viewer 403 / 治理只读 / 工程师建改试运行 / 管理员发布停用；跨租户列表 0 + 按 code 探测 404）。
