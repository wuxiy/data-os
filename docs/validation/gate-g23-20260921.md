## dev 真实链路证据（2026-09-21，镜像 0.2.0-g23-20260921 三服务 + 门户 dist）

- **导入→验证→评审→生效→影响→回退（ods_ep.ep_mz_cfzb）**：
  1. 发布对齐真实列的标准 STD-EP-CFLX-01（CODE cflx 值域 WESTERN_MEDICINE/TRADITIONAL/OTHER + STRING hzxb + INTEGER record_id + DATETIME kfrq），发布即 SYNCED（复用 G22 OM 词表）；
  2. 建映射集 MAP-EP-CFZB（空草稿）→ CSV 导入 dry-run（4 项，problems=[]，checksum ed55f037…）→ 落库；
  3. 聚合验证（真实 Doris，11423 行）：CFLX varchar→CODE 兼容、覆盖率 **99.86%**、未映射 TOP N=[10:7, 5:4, 3:2, 9:1, 8:1, 2:1]、空值率 0；ID bigint→INTEGER、KFRQ varchar→DATETIME（DATE_FORMAT）兼容 → **PASS**（checksum 与版本一致）；
  4. 提交 → 生效（ACTIVE，活动指针 v1）→ 影响范围（4 数据元全映射、uncovered=[]、验证 PASS）；
  5. v2 扩充 VALUE_MAP 全量值域 → 验证 PASS（CFLX 覆盖率 1.0）→ 生效（v1 RETIRED 被取代）→ **回退 v1**（v2 RETIRED、v1 ACTIVE，事件链 ROLLED_BACK→RETIRED→ACTIVATED→RETIRED→VALIDATED→SUBMITTED 全留痕）；
