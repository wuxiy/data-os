## 三、本批关键工程发现（载荷性）

1. **Doris stream load 标签 ≤128 字符**：label = 前缀 + 库 + 表 + 作业号 + 序列；institution_drug_catalog_verify_detail 等长表名作业以 `Label format error` 拒绝。解法：超长作业换短 label 前缀（idcsl/idcvd）。**新表名超 ~30 字符时前缀须预算**。
2. **质量规则选择器 ≤42 字符（失败表名 64 预算）**：runner 契约为 `<20 字符命名空间>__<selector>` 留预算；institution_drug_catalog 族选择器全超，dbt 失败表建不出来 → 18 条规则首跑失败。解法：选择器统一缩写（idc 族），rule_id 不变（registry 按 rule_id upsert 无残留）。**后续新增规则的 selector 长度须先算预算**。
3. **DM CLOB 类型**：DRUGSTORE 等表有 CLOB 列，映射 Doris STRING（DDL 头注明）。
4. **脏 FK 边（数据质量发现，不注册规则）**：verify_detail→verify 1 孤儿、record→drug_catalog 1 孤儿、drug_catalog→institution_drug_catalog 438 悬挂引用（源库删除目录未级联清引用的形态）。
5. PH discipline：patient_address 全列入仓（CONTACT/PHONE/ADDRESS 为 PHI：仓内有 API 面无，证据白名单不含）；DRUGSTORE.CREDENTIALS 为药店资质文档（业务主体信息，非患者 PHI、非账号凭证），保留并在本报告留痕。
