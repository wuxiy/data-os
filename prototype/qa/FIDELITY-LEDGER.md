## 文案差异

概念稿中的“资产覆盖率、标准映射率、规则覆盖率”等示例指标，在实现中调整为“标准覆盖率、质量规则通过率、问题按时闭环率、血缘完整率、标准映射覆盖、有效数据合同”。这是有意修改：实现文案与平台蓝图的治理一级页面保持一致，不属于遗漏。

左上角盾牌十字符号已按复核结论删除，替换为三个相连节点的产品标记。右侧抽屉采用覆盖式而不是概念稿的占位式布局，避免主视图随抽屉开启发生重排。

## 核心流程验证

1. 管理驾驶舱 → 打开治理责任链 → 查看关联键与节点来源。
2. 数据标准 → 选择“疾病诊断编码” → 右侧详情同步更新。
3. 标准映射 → 仅看待确认 → 详情自动切换到仍可见的待确认字段 → 保存并显示版本反馈。
4. 数据质量 → 开始复检 → 按钮进入禁用运行态 → 时间线新增复检事件。
5. 主索引审核 → 勾选确认 → 建立身份关联 → 操作进入不可重复提交状态。
