# 医数中枢第一版原型 · 概念审查清单

## 采用方向

- 产品壳层：232px 无渐变深灰松石侧栏、温润灰米白画布、白色开放工作面。
- 信息路径：机构与时间范围 → 当前状态 → 可下钻事项 → 治理责任链。
- 核心记忆点：异常发现 → 数据对象 → 治理规则 → 责任部门 → 处理结果。
- 字体关系：宋体结构的页面标题、无衬线操作文字、等宽指标数字。

## 六页信息库存

| 页面 | 首屏主要内容 | 核心操作 |
|---|---|---|
| 管理驾驶舱 | 今日关注、关键指标、30 日趋势、风险排行、交付状态 | 从风险进入治理责任链 |
| 治理驾驶舱 | 治理指标、责任链、质量趋势、风险排行、今日待办 | 点击异常打开责任链抽屉 |
| 数据标准 | 分类树、标准列表、标准详情、版本轨迹 | 切换标准与详情标签 |
| 标准映射 | 源字段、映射矩阵、校验结果、影响与版本 | 选择字段并保存映射 |
| 质量闭环 | 问题队列、处理轨迹、影响对象、证据、处理说明 | 开始复检并提交说明 |
| 主索引审核 | 候选队列、三方字段对比、匹配证据、影响分析 | 勾选确认后建立关联 |

## 图标库存

仅使用 Lucide 线性图标：`House`、`Cable`、`Database`、`Landmark`、`Fingerprint`、`Workflow`、`ChartNoAxesCombined`、`Boxes`、`PackageCheck`、`Settings`、`Menu`、`Search`、`Bell`、`ChevronRight`、`X`、`Check`、`AlertTriangle`、`Clock3`、`ArrowRight`。不使用 emoji 或手工 SVG 图标。

## 文案边界

- 首屏只呈现机构范围、截至时间、结果、风险和可执行事项。
- 不向业务用户暴露 dbt、OpenMetadata、SeaTunnel 等底层引擎名。
- 指标必须有单位、目标或更新时间；异常必须有责任对象和下一步动作。

## 实现偏差（经审查后主动调整）

1. 删除概念图中的盾牌/十字符号，改为由三个相连节点构成的代码化产品标记。
2. 责任链详情采用覆盖式右侧抽屉，不压缩主表与图表。
3. 小于 768px 时宽表转为摘要列表，抽屉占满屏幕。
4. 采用治理驾驶舱 v2 的低饱和配色；责任链展示事件编号、关联键、生成/刷新时间与逐节点来源。

## 责任链来源模型

| 节点 | 关联键 | 数据来源 |
|---|---|---|
| 异常发现 | `issueId` | 质量规则运行结果 |
| 数据对象 | `assetId` | 资产目录与采集元数据 |
| 治理规则 | `ruleId` | 质量规则中心 |
| 责任部门 | `ownerId` | 资产责任人与组织主数据 |
| 处理结果 | `ticketId` | 治理工单 |

## 最终实现结论

治理驾驶舱 v2 被确定为实现基准。真实渲染通过 1440×900 和 1280×800 桌面复核，详细对照、文案差异与交互验证见 `qa/FIDELITY-LEDGER.md`。
